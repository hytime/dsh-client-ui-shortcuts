# DSH Claude Shortcuts

当前项目已保存实现计划，功能代码按计划逐步实现：

- 计划：[Claude shortcuts implementation plan](docs/superpowers/plans/2026-08-17-claude-shortcuts-plan.md)
- 目标插件包：`@hytime/dsh-client-ui-claude-shortcuts`
- 参考项目：`dsh-companion`、`dsh-pi-effort`

计划文档和 superpowers 工作资料仅用于本地开发，不纳入远端提交。
